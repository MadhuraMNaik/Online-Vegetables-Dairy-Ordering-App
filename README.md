# Online Vegetables & Dairy Products Ordering App

An Android-based application for ordering vegetables and dairy products online using Firebase.

## Features

- User Registration and Login
- Browse Vegetables and Dairy Products
- Product Details
- Online Ordering
- Order Management
- Firebase Integration
